# GamoraVet Android MVP

Versão Android de teste do MVP GamoraVet.

## Build
O GitHub Actions gera automaticamente um APK de teste em:
Actions → Build GamoraVet APK → Artifacts → GamoraVet-debug-apk

## Observação
Esta versão Android encapsula o MVP navegável local em WebView.
A próxima etapa é substituir o armazenamento local por backend, autenticação e notificações nativas.
